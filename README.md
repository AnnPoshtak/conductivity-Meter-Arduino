# Кондуктометр — Лабораторний журнал

Вебінтерфейс для вимірювання електропровідності розчинів із плати Arduino.

## Вміст папки
Усі файли мають знаходитися в одній папці:
- `server.py` — локальний сервер для зчитування даних з Arduino
- `index.html` — головна сторінка приладу
- `style.css` — оформлення
- `script.js` — логіка роботи та графік

## Підготовка до запуску (один раз)
1. Переконайтеся, що встановлено **Python 3**
2. Встановіть бібліотеку `pyserial` для роботи з USB-портом. Відкрийте термінал (або командний рядок `cmd` на Windows) і виконайте команду:
```bash
pip install pyserial
```

## Як запустити роботу
1. Підключіть Arduino із завантаженим скетчем до USB-порту комп'ютера.
2. Відкрийте папку з проєктом у терміналі / командному рядку (на Windows можна натиснути правим кліком у папці → **Відкрити в терміналі**, або ввести `cmd` в адресному рядку Провідника та натиснути Enter).
3. Запустіть сервер командою:
```bash
python server.py
```
або
```bash
python3 server.py
```
4. Коли в консолі з'явиться повідомлення `Відкрийте у браузері: http://localhost:8000`, перейдіть за цим посиланням у будь-якому браузері.

## Можливі проблеми та їх вирішення
- **«Пристрій не знайдено»** — перевірте надійність підключення USB-кабелю або закрийте програму Arduino IDE (якщо там відкритий Монітор порту, він блокує доступ до плати для Python).
- **На Windows не визначається плата (китайський клон Arduino на чипі CH340)** — зазвичай Windows 10/11 встановлює драйвер автоматично, якщо ні — потрібно завантажити та встановити драйвер `CH341SER`.
- **Не відображається графік** — для першого завантаження бібліотеки побудови графіків (`Chart.js`) комп'ютер повинен мати підключення до інтернету.
